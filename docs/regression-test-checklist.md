# 회귀 테스트 체크리스트

> 배포 전 수동 점검. `python3 -m http.server 8000` 후 `http://localhost:8000`에서 확인.
> 자동 스모크 점검(선택): 순수 함수 로직은 Node DOM 목으로 검증 가능.

## 기본 기능 (기존)
- [ ] 앱 최초 실행 / 온보딩 안내 1회 표시
- [ ] 리그 이동 (루키·프로·마스터)
- [ ] 강의 이동(이전/다음, 상단·하단 버튼)
- [ ] 진행률 계산(전체·리그별)
- [ ] 실습값 저장 → 새로고침 후 유지
- [ ] 체크리스트 저장
- [ ] 완료 후 다음 강의 이동
- [ ] 결과물 복사
- [ ] 초기화(확인창)
- [ ] 발표 모드 진입/이동/닫기(←→ N Esc)

## 진행 코드 (기기 이동)
- [ ] ‘진행 내보내기’ → 코드 복사
- [ ] 초기화 후 ‘진행 불러오기’ → 상태 완전 복원
- [ ] 잘못된 코드 입력 시 앱 멈춤 없이 경고
- [ ] 재방문 시 마지막 리그·강의로 자동 복귀

## 학습 기록 백업·복원 (파일, Phase 1)
- [ ] ‘파일로 저장’ → `vibecoder-progress-YYYYMMDD.json` 다운로드
- [ ] ‘파일에서 복원’ → 정상 JSON 복원(진행률·실습값·완료 상태)
- [ ] 잘못된 JSON 처리(앱 멈춤 없음)
- [ ] 구버전(데이터만) JSON 호환
- [ ] 덮어쓰기 전 확인창

## 포트폴리오 (Phase 2)
- [ ] Markdown 출력
- [ ] HTML 출력
- [ ] 인쇄·PDF(인쇄 미리보기)
- [ ] 빈 항목 자동 제외
- [ ] 한글 깨짐 없음
- [ ] 사용자 입력 스크립트 미실행(이스케이프)

## 코드 미리보기 보안 (Phase 3)
- [ ] 일반 HTML 실행
- [ ] JavaScript 버튼 동작
- [ ] 부모 DOM/localStorage 접근 차단(`window.parent...` 실패)
- [ ] API 키 의심 문자열 경고 표시
- [ ] ‘미리보기 중지’ 동작
- [ ] 미리보기 오류 시 앱 본체 정상

## 메타데이터·수료 기준 (Phase 4 — 전체 44강 적용 완료)
- [ ] 모든 강의에서 난이도·예상 시간·확인일 표시
- [ ] 모든 강의에서 "완료(수료) 조건 보기" 펼침 동작
- [ ] 세 리그 모두 핵심 역량·최종 결과물·수료 기준 표시

## 리그별 실생활 캡스톤
- [ ] 배포 링크(`deployUrl`) 입력 후 결과물 저장소 최상단에 "내 완성 앱" 요약 노출
- [ ] 배포 링크 미입력 시 캡스톤 요약 숨김(정상)
- [ ] 세 리그 모두 캡스톤 deliverable/doneCriteria/useInDailyLife 표시
