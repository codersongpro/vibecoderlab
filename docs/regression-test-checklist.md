# 회귀 테스트 체크리스트

> 배포 전 수동 점검. `python3 -m http.server 8000` 후 `http://localhost:8000`에서 확인.
> 자동 스모크 점검(선택): 순수 함수 로직은 Node DOM 목으로 검증 가능.

## 기본 기능 (기존)
- [ ] 앱 최초 실행 / 온보딩 안내 1회 표시
- [ ] 리그 이동 (루키·프로·마스터)
- [ ] 강의 이동(이전/다음, 상단·하단 버튼)
- [ ] 진행률 계산(전체·리그별)
- [ ] 실습값 저장 → 새로고침 후 유지
- [ ] 체크리스트 저장
- [ ] 완료 후 다음 강의 이동
- [ ] 결과물 복사
- [ ] 초기화(확인창)
- [ ] 발표 모드 진입/이동/닫기(←→ N Esc)

## 재방문 복귀
- [ ] 재방문 시 마지막 리그·강의로 자동 복귀

## 현장·일상 프로젝트 아이디어 (Phase 5)
- [ ] ‘현장·일상 프로젝트 아이디어’ 패널 펼치면 5개 카테고리·15개 아이디어 표시
- [ ] 각 아이디어에 추천 리그 배지(루키/프로/마스터) 색상 구분 표시
- [ ] ‘이렇게 씁니다’ 활용 안내 표시
- [ ] 패널은 진행 상태와 무관하게 항상 보임(리그 이동해도 그대로)

## 자동 점검 루브릭 (Phase 6)
- build 실습(루키 ‘만들기’)에서 HTML 붙여넣기 → 아래에 ‘자동 점검’ 카드 표시
- [ ] 구조·제목·언어·이미지 alt·입력칸 안내·비밀 값 항목이 통과/주의/위험으로 표시
- [ ] 비밀 값(예: `AIza…`)이 든 코드 → ‘위험’ 등급, 빨간 배지
- [ ] 코드 비우면 ‘주의(코드 입력)’ 한 줄만 표시
- [ ] 입력 수정 시 즉시 갱신
- [ ] 포트폴리오(MD·HTML·인쇄)에 ‘내 앱 자동 점검’ 요약 포함(붙여넣은 HTML이 있을 때만)
- [ ] 자동 점검은 코드를 실행하지 않음(문자열 패턴만 검사)

## 진행 코드 수합 — 무설치 진도 집계 (증분 4)
- ‘완료율 코드 만들기’ 패널에서 이름 입력 → 코드·QR 자동 생성
- [ ] 코드 복사 버튼 동작
- [ ] 작성한 실습 텍스트(개인정보 포함 가능)는 코드에 담기지 않음(완료 개수만)
- [ ] 같은 브라우저에서 `index.html?mode=collect`로 접속 시 일반 화면 대신 수합 화면만 표시
- [ ] 코드 2~3개를 붙여넣고 ‘추가’ → 이름·리그별 완료율·전체 % 표 생성
- [ ] 형식이 잘못된 텍스트를 섞어 붙여넣어도 앱이 멈추지 않고 유효한 코드만 반영
- [ ] 같은 이름으로 다시 제출 시 덮어쓰기(중복 행 생성 안 됨)
- [ ] ‘표 복사’ → 스프레드시트에 붙여넣을 수 있는 탭 구분 텍스트
- [ ] ‘전체 삭제’ 확인창 후 목록 초기화
- [ ] 새로고침해도 수합 목록 유지(별도 localStorage 키, 학습 기록과 분리)
